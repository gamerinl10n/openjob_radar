# OpenJob Radar

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](./LICENSE)

공개 채용 공고를 사람이 요청했을 때만 수집하는 review-first 오픈소스 도구입니다. 데이터베이스나 자동 게시 기능 없이 검토 가능한 JSON을 만듭니다.

이 프로젝트는 [DREAMDURIM](https://github.com/gamerinl10n/dreamdurim)의 공고 수집 코드에서 시작했으며, 원본 이력을 보존해 독립 저장소로 분리했습니다. 자세한 출처는 [NOTICE](./NOTICE)를 참고하세요.

## 지원 출처

- [월드잡플러스](https://www.worldjob.or.kr/advnc/cnttNewList.do?showItemListCount=30)
- [재외한국문화원](https://www.korean-culture.org/recruitmentNoti.do)
- [KOTRA 본사 채용](https://www.kotra.or.kr/subList/20000005817)

각 출처의 공개 페이지에만 접근합니다. 로그인 우회, 브라우저 자동화, JavaScript 실행은 하지 않습니다.

## 로컬 사용법

Node.js 22 이상과 npm을 사용합니다.

공고 수집용 GitHub Actions나 예약 실행은 제공하지 않습니다. GitHub Actions는 Windows 설치 파일 빌드와 테스트에만 사용합니다. 수집은 아래 로컬 명령을 직접 실행한 경우에만 시작합니다.

```bash
npm ci
npm run collect -- --source kotra
npm run list
```

명령어 대신 로컬 관리 화면을 사용할 수도 있습니다.

```bash
npm run app
```

터미널에 표시되는 `http://127.0.0.1:4174`를 브라우저에서 열면 출처 선택, 수동 수집,
검토 목록 확인, 승인과 제외를 한 화면에서 처리할 수 있습니다. 관리 화면은 내 컴퓨터에서만
접속할 수 있고, 브라우저를 열거나 서버를 실행하는 것만으로 수집을 시작하지 않습니다.
포트를 바꾸려면 `OPENJOB_RADAR_PORT` 환경 변수를 사용하세요.

출처를 생략하면 세 출처를 모두 확인합니다. 쉼표로 여러 출처를 지정할 수 있습니다.

```bash
npm run collect -- --source culture,worldjob
npm run collect -- --source kotra --dry-run
```

결과는 어떤 웹사이트에도 자동으로 게시되지 않습니다.

- `data/review.json`: 등록 후보와 사람이 확인해야 할 공고
- `data/last-run.json`: 최근 실행 결과 및 제외 사유
- `data/state.json`: 다음 월드잡 페이지 위치
- `data/approved.json`: 사람이 확인하고 승인한 공고 기록

원문과 `review.json`을 확인한 뒤 다음처럼 승인합니다.

```bash
npm run approve -- --id radar-example
npm run reject -- --id pending-example
npm run check
git diff
```

승인은 `data/approved.json`을 수정합니다. 필요한 서비스가 이 파일을 별도로 가져가 사용할 수 있으며, 수집기 자체는 외부 서비스로 전송하거나 게시하지 않습니다.

## 설계 원칙

- 모든 실행은 사용자가 로컬 명령을 입력했을 때만 시작합니다.
- 공고는 자동 게시하지 않습니다.
- 원문 URL로 중복을 제거합니다.
- 이미지·HWP·조건 누락 공고는 확인 필요 목록으로 보냅니다.
- 원문 이미지와 첨부파일을 복제하지 않고 링크와 구조화된 사실만 기록합니다.
- 출처 구조를 읽지 못한 경우 공고 0건으로 오인하지 않고 실패로 기록합니다.

## 기여

새 출처는 `src/sources.js`와 전용 파서를 추가하고, 정상 목록·빈 목록·구조 변경·상세 실패 테스트를 포함해야 합니다. 출처의 이용약관과 robots 정책을 확인하고 요청량을 제한하세요.

개발 절차와 제출 기준은 [CONTRIBUTING.md](./CONTRIBUTING.md)를 참고하세요.

## Windows 데스크톱 앱 (0.6.0)

Windows 10/11 x64용 독립 창 앱입니다. 설치 후에는 Node.js나 터미널이 필요하지 않습니다.
GitHub Actions의 **Windows desktop build** 실행 결과에서 `OpenJob-Radar-Windows`를 내려받아,
압축을 풀고 `OpenJob-Radar-0.6.0-Setup.exe`를 실행하세요.
현재 빌드는 코드 서명 인증서를 포함하지 않으며 Windows에서 게시자 확인 경고가 표시될 수 있습니다.

- 수집은 버튼을 눌렀을 때만 시작합니다. 공고 조회에는 인터넷이 필요합니다.
- 기존에 저장한 공고의 조회·수정·승인·제외는 인터넷 없이 사용할 수 있습니다.
- 확인 필요 공고는 **상세 · 수정**에서 업무와 자격 등을 채우면 등록 검토로 이동합니다.
- 검색과 출처 필터를 사용하고 승인·제외 기록을 다시 열어볼 수 있습니다.
- **파일 → 데이터 폴더 열기**로 실제 저장 위치를 확인하세요. 설치 폴더와 분리되어 업데이트 후에도 유지됩니다.
- 기존 CLI 데이터는 앱을 종료한 상태에서 해당 데이터 폴더에 복사할 수 있습니다. 기존 파일을 덮기 전 따로 백업하세요.
- 작업 중 중복 실행을 막고, 중단된 저장은 다음 CLI 작업에서 저널을 읽어 복구합니다.
- 공고를 제외하면 이후 수집에서 같은 URL을 검토 목록에 다시 넣지 않습니다.

개발 실행과 Windows 설치 파일 생성:

```bash
npm ci
npm run desktop
npm run check
npm run dist:win
```

Windows에서 빌드하는 것이 기본 경로입니다. Linux에서 NSIS 설치 파일을 교차 빌드하려면 Wine이 필요합니다.

## 0.6.0: 수집 상태와 검토 작업실

- 출처마다 최근 시도·최근 성공·실패 사유를 표시합니다. 화면의 상태는 마지막 수집 결과이며 실시간 연결 검사 결과가 아닙니다.
- **실패 출처만 재시도**는 실패한 출처만 다시 읽습니다. 확인 필요 공고도 다시 조회하여 일시적인 실패에서 회복할 수 있습니다.
- 넓은 창에서는 목록 옆에서 공고를 수정하고 이전·다음 공고로 이동합니다. 좁은 창에서는 상세 패널이 목록 아래에 표시됩니다.
- 저장하지 않은 내용을 두고 이동할 때 확인하며, 검색 조건과 마지막 목록을 다음 실행에 복원합니다.
- **제외 기록 → 선택 제외 취소**로 원래 검토 목록에 돌려놓을 수 있습니다. CLI에서는 `node src/cli.js unreject --id <ID>`를 사용합니다.
- **백업 다운로드**는 검토·승인·제외·수집 위치·보고서·출처 상태를 하나의 JSON 파일로 저장합니다.
- **백업에서 복원**은 백업으로 현재 데이터를 교체합니다. 10MB 이하의 올바른 백업만 허용하며, 복원 직전 자료는 데이터 폴더의 `backups/`에 자동 보관합니다. 이 파일로 이전 상태를 다시 복원할 수 있습니다.
- 수집 중에는 백업·복원과 다른 수정 작업이 겹치지 않도록 차단합니다.


### v0.6 · 수집 범위와 검토 보조

- **확장 수집**: 앱에서 수집 범위를 선택하거나 `npm run collect -- --depth extended`를 실행합니다. 월드잡은 최신 목록과 이어보기 최대 5페이지, KOTRA는 최신 최대 5페이지, 문화원은 공식 링크로 확인된 최대 5페이지를 조회합니다. 출처별 상세 조회는 최대 150건이며, 사이트 응답·마감·지역 조건에 따라 실제 저장 건수는 줄어듭니다. 요청 동시 실행 제한은 그대로 유지합니다.
- **확인 사유**: 이미지, 첨부파일, 마감일, 근무지, 업무, 자격, 조회 실패를 구분해 필터링합니다. 읽어낸 필드는 확인 필요 공고에서도 보존합니다.
- **변경 비교**: 활성·승인 공고를 다시 조회하고 원문 기준값과 비교합니다. 사람의 수정 내용이나 승인 데이터 필드를 자동 덮어쓰지 않습니다. 기존 버전의 공고는 첫 재조회에서 비교 기준을 만들고, 다음 조회부터 변경을 표시합니다. 원문 마감·분석 문제도 별도 안내합니다.
- **중복 출처**: 회사·제목·도시·국가·마감일이 일치하는 후보는 기존 공고에 다른 출처 링크를 보관합니다. 유사 제목을 임의로 합치지 않습니다.
- **관심 조건**: 쉼표로 구분한 키워드 중 하나와 일치하는 공고만 표시하고, 마감 빠른 순·원문 변경 먼저 정렬을 지원합니다. 마감일 없는 공고는 마감순 정렬의 뒤에 표시합니다. 개인 화면 설정은 해당 컴퓨터에 기억됩니다.

수집은 버튼을 누를 때만 실행합니다. 확장 수집은 조회 범위를 넓히며, 조건에 맞는 채용 공고 수 자체를 보장하지 않습니다. 이미지 OCR과 새 출처 연결은 포함하지 않습니다.
